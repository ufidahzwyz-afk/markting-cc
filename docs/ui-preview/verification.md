# 新版管理界面验收

验证日期：2026-10-03。环境：Node 24.19.0、Next.js 16.3.8、Chromium。新版以紧凑导航、可操作表格和右侧详情替代原来的展示卡片。

## 模块分别验收

| 模块 | 本轮验证 | 结果 |
| --- | --- | --- |
| 今日工作 | 日期/负责人/状态/搜索筛选、空结果重置、任务步骤与阻塞详情、模拟处置及日志更新；未完成任务不因处置变成执行完成 | 通过 |
| 推广主题 | 业务线/状态/搜索/排序、批量暂停、编辑受众与推进任务、新建主题、保存后刷新保留、任务页提交仍校验必填主题名 | 通过 |
| 效果复盘 | 独立代理完成 12 项浏览器验收：日期/渠道/维度/排序/图表、CSV 实下载及内容回读、明细、口径、真实接入缺口、手机适配 | 12/12 通过 |
| 连接与规则 | 设置页与抽屉、三类执行开关不可开启、资料与账号未连接状态、Escape 关闭 | 通过 |

负责人统一为两名运营人员。所有新建、编辑、处置及导出均限定模拟数据，没有真实业务写入。主题本地保存与今日工作临时处置的范围在界面中分别说明。

## 当前界面联调

- 四个路由 HTTP 200；1440×1000、390×844 均无文档级横向溢出。宽表格在自身容器中滚动。
- 页面脚本错误为空。报表 SVG 标题的服务端/浏览器文本不一致问题已修复并重新验证。
- 主题从新建、编辑、保存、刷新到再次读取的流程通过；任务处置、统计与运行记录语义一致。
- `npm run check` 通过：类型检查、3 项访问控制/报表汇总测试、管理台生产构建。
- 独立生产构建以 `APP_ENV=production AUTH_MODE=mock` 运行：内部页面/API 返回 503；最小健康入口返回 200。模拟身份不能在生产放行。
