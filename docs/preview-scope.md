# 界面确认版本

依据：产品 V1，PRD 修订 1.2，业务基线 V1.4。

本轮交付可点击的管理台界面，用于确认信息层级、导航、任务状态和例外处理方式。主导航为今日工作、推广主题、效果复盘，连接与规则位于设置。主题新建、编辑、批量状态和推进记录保存到当前浏览器本地模拟空间，不构成两人共享后端。任务处置只记录本页动作，不宣称完成真实执行。报告默认展示固定模拟报表，真实数据页显示待接入。页面只展示明确标注的模拟数据；全部真实发布、广告写入和个人信息处理开关关闭。

当前完成标准：三入口可访问、筛选与详情交互可用、390px 和 1440px 无意外横向溢出、键盘可操作、未配置生产身份时内部页面和接口拒绝访问。

数据库迁移和其他包配置是暂停保存的工程草稿，尚未验证或启用。界面确认后，按独立任务进行实现和验收，再完成端到端联调。真实账号、来源、发布及效果验收继续依照原 PRD；界面通过不代表 V1 功能通过。

公开仓库保留源码、匿名测试数据和工程说明；原始业务资料及凭据保存在隔离工作区。
