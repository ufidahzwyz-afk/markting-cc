## 已实施

- 保留原 OpenAPI 核心规范并补普通 CRUD/来源读取；同步导入、报告及安全 DTO 的实际响应与状态码明确列出，异步接口才返回真实 workflow。AI v2 全8流程与页面全部10模块提供生成 TypeScript 类型及 AJV2020 运行校验。原文 PRD、原会话和凭据没有放入仓库。
- AI 语义核验限制既有 ID、来源 revision/时间/coverage、平台档案、负责人规则与确定性执行/报表输入；模型不能确认用户未表达的决定、扩张授权或伪造已执行结果。Mock 是真正 v2 空提议和独立 simulation 元数据；real 缺配置显式失败。
- 来源 reader 统一 changed/no_change/partial/failed 接口。四源默认 NOT_CONFIGURED，ChatGPT独立会话或项目范围与实际会话/消息/分支定位必填，模型 API 不提供对话访问权。服务器事务保存不可变来源版本，完整成功提交后才推进全局水位；部分覆盖仅保存已取得版本并标记 partial，失败、同revision篡改、过期并发水位均不推进。
- 7产品族、22业务领域、17服务、7行业仅导入必要名称/键/成员别名与来源引用投影，共53条。再次初始化保留当前映射和新确认；项目制造三种表述同key，BIP映射用友云产品族，U8Cloud保持待确认，YonWork不等同WorkBuddy。未知行业保持null。投影快照标注工程来源，不能冒充原始统计证据、平台读回或真实品牌许可。
- 事实、推断、用户决定独立登记；初建事实 unverified/public_permission=unknown。核实与公开许可分别留痕；撤销/失效阻断依赖主题及未执行动作。客户端不能提交 confirmationproof 自行升级用户批准。
- priority_score始终null；缺门槛 blocked，商业意图/可交付/健康承接为P0，一般教育P1，探索P2。同级最新来源时间后稳定ID排序。自动排期逐次核对现行有效规则、同组织账号/计划、公开证据、实测连接、上海时区窗口和日周频率；并发预留通过数据库事务串行化。
- HTTP接口接入主数据/16渠道、来源、证据、主题CRUD及自动排期；生成类接口创建持久workflow。真实来源缺连接返回503且保存needs_human/failed，水位不动。账号元数据存在不等于凭据已配置；过期或不健康渠道保持pending。source.changed消费器在固定部署组织内重新核对当前成员、来源版本/范围、批准规则及网关，以来源版本幂等派生derive_insights；缺口持久needs_human，不自动批准事实。
