# T5 百度执行与确定性指标

状态：工程控制已实现并通过隔离测试；真实百度集成 **blocked / 尚未验收**。本任务不代表生产账号接通，不代表 V1 产品完成。

## 已实现

- `packages/domain/src/ads.ts`：CSV/标准行预检、原始内容 SHA256 校验、批次防重、预检→提交状态、自然键修订与旧水位保护。同水位不同值拒绝；未提交同hash批次可显式更正为更新水位并审计，已提交批次不改证据；仅 rejected 批次可显式更正列 mapping 后重预检，validated/committed 不可重映射；缺日期、负值、非法金额 minor、未知/混用币种、字段缺失、重叠汇总粒度可定位。
- 总量只来自连接配置的权威报表；关键词只作细分。缺失日期保持 null；期间不完整时完整窗口总量不可用，同时展示已观察到的部分金额。跨币种不相加，零分母不伪造比率。
- 固定广告字段、子操作、对象白名单；写前 `expected_before_hash` 实际比较；规则有效期、账号、预算、地域、时段及出价幅度复核。真实近期花费和原生双预算通过私有 `refreshBaiduReadiness` 写入可信 settings，公开请求不能提供 readiness。
- 否词必须匹配真实搜索词完整短语、同单元或显式账户范围、批准观察窗口、完整数据和匹配方式；商业词根及迁移/集成/价格等商业意图受保护。
- 创意须匹配已质检不可变版本，引用事实检查公开许可与有效性；新落地页须在规则域名内并经注入适配器验证页面与移动留资。
- `executeBaiduAction` 使用 T1 授权/租约/fencing 与执行证据，注入百度 write/readback。提交或超时不能直接成功；unknown 必须对账。Mock 回读只到 `verification_pending`，不成为真实成功。
- `apps/ops/src/lib/handlers/ads-reporting.ts`：canonical 导入请求、历史导入固定来源身份、批次查询/提交、指标查询与当前窗口 CSV。只读取可信上传对象或明确隔离 fixture；不读取客户端任意本地路径/URL。

## 真实验收缺口

AC32 / 百度所属 AC47 尚未执行：无真实账号、API/浏览器授权、实测能力、批准预算、实际花费与原生控制证据。须逐项真实验证计划/单元/关键词/否词/创意/链接/地域/时段/出价/启停，保存动作前后状态、审核与回读。

公开 CSV 是历史迁移/恢复功能；不能替代持续取数。生产上传对象存储仍需实际接入。自动效果调优和 paid CPL 仍不可用，须另外批准归因/成熟期并取得同 cohort 真实线索。百度例外审批需与 T1 授权执行及明确预算范围联调；当前专用百度执行器只接收持续规则内动作，不以不完整例外权限绕过预算。
