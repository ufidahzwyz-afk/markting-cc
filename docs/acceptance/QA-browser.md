# T4 浏览器独立验收

`tests/integration/browser-security.test.ts` 的 7 项隔离测试通过。测试使用真实事务数据库、HTTP 请求、独立签名的测试 OIDC JWT；平台读回证明是测试夹具，没有登录或发布到真实平台。

已核实的工程控制：

- 三个同时争抢的账号只得到两份全局租约，同一账号的两个并发请求只得到一份租约；状态与 fencing token 持久化。
- 其他组织不能读取命令或取得登录票据；用户当前数据库角色被降为 viewer 后，旧上下文不能创建或兑换票据。服务身份不能控制人工登录票据。
- 首次 HTTP 登录响应只返回一次票据；同一幂等键重放返回空票据、空交互地址。登录记录、幂等记录和审计记录均不含票据明文；其他用户不能兑换。票据在第 60 秒失效，交互期限是独立的 900 秒；停用成员及交互到期立即失去权限。
- 未知发布结果不能重新执行写入。独立对账命令核对原动作、账号、标签及原始载荷 SHA256，缺少或错误的内容哈希不能把原命令改为成功。
- 服务 OIDC 中伪造的组织声明不提供权限，部署配置的明确组织白名单才有效。live 适配器缺配置返回 HTTP 503，并持久保存 blocked、未核验状态。CDP 路径不可访问。

独立检查发现并已由浏览器模块负责人修复：登录操作仅检查成员 active、未重新检查当前角色；发布及发布对账没有绑定原动作内容哈希；live 未配置执行统一返回 200。上述修复均有独立回归用例。

```sh
node --import tsx --test tests/integration/browser-security.test.ts
```

真实验收仍待外部接入：加密卷和 Chromium 配置、受控登录代理与一次性入口、平台 MFA、真实帐号读回、标签及文章内容核验、实际百度 API/原生控件读写、云端 OIDC 部署与重启恢复。上述测试不证明真实平台已经接通，也不替代执行规则与预算门禁的独立测试。
