# T4 浏览器与逐平台边界

## 已实现并验证

- 固定私有命令 schema/HTTP；拒绝任意 URL、JS、shell、CDP 和未知命令。默认缺 OIDC 为 503。
- Google RS256 OIDC 签名、issuer、audience、有效期、允许服务账号及显式组织校验。测试使用本地密钥生成真实签名 JWT，错误 audience、身份、过期和跨组织均被拒绝。
- browser_commands 持久状态与不可变输入哈希；相同幂等键重放相同命令，变更载荷冲突。
- 数据库每账号互斥、总并发 2、fencing/session versions、过期租约恢复、unknown 先对账、challenge 暂停。
- 登录票据 hash、60 秒一次兑换、900 秒交互、用户/组织/账号/成员有效性/当前可操作角色/会话版本绑定；Mock 不能完成真实核验。
- 独立 profile 路径与持久文件锁、全节点两个 slot、关闭浏览器后才解锁；本地真实 Chromium 验证隔离、重开和禁止 localhost 导航。
- 16 个独立平台 descriptor、各自固定导航 origin、格式与能力验证 hook；发布提交后要求独立读回、标签证据与绑定授权正文哈希一致。百度包含受限原生 JSON API 方法边界、账号与能力验证门槛。
- 管理台连接/账号/会话 API 使用安全 DTO，不返回 secret_ref、profile、Cookie 或票据 hash。首次登录票据独立幂等路径，仅首次返回 raw ticket，缓存只存引用。
- 私有进程每秒轮询持久浏览器队列；worker 消费到期、已授权的 external.publish/ads 动作。调度组织来自部署配置，模式写入不可变命令输入；模式切换不能把模拟命令升级为真实执行。缺 OIDC、平台 hook 或写入开关时持久 blocked，并记录缺失能力。
- 执行动作与浏览器分别领取租约及 fencing token；心跳、账号锁和总并发 2 继续生效。两个 worker/dispatcher 争用同一动作只提交一次；unknown 不进入写入队列。发布前再次复核当前账号时区的批准窗口，独立读回成功后才更新 publish_job 与 execution_action。

验证命令：`CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test --workspace @boran/browser-runtime`。本轮 28/28 通过，包括 OIDC、数据库恢复、真实本地 Chromium 与 durable dispatcher 集成；browser-runtime 和 worker typecheck 通过。调度集成使用隔离 PGlite、真实规则/动作授权、可审查的进程内证据 hook，并未调用真实平台。
