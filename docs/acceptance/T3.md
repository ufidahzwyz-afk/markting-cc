# T3 内容与官网验收记录

状态：工程隔离验证已实现；真实域名、生产模型、真实平台账号与实际客户表单验收尚未完成。

## 已实现

- 主题绑定内容身份、不可变正文版本及公开事实引用；事实需 verified/fact/public/allowed、有许可依据且未过期。proof 不扩写事实，案例结果/上线/验收需要对应证据。
- 平台变体独立绑定账号、受众/样稿/规则版本、格式、实际素材与 AI 标识状态。跨平台相同正文仅换标题被阻断；视频脚本不能代替视频文件。
- 实际媒体 state、许可、存储对象、字节哈希和类型签名校验。未知许可、缺实际文件或无存储核验能力保持阻断。
- 严格原始十类模块 Schema、纯文本白名单、同域规范地址、批准路径、旧站路径冲突防护。服务/行业模板必需模块及表单隐私接收门槛检查。
- 新 release 与 page 指针在同一事务中提交，正文与 release 不可变；回滚追加 release，历史全部保留（测试超过十版）。重复动作不重复创建 release。
- 指针切换后为 verification_pending，实际 HTTP 读回核对 release ID、正文 hash、主标题及关键可见正文、可用表单控件与媒体引用后才核验；脚本/style/JSON-LD 不能充当可见正文。mock 读回保存独立模拟证据、仍保留 verification_pending，不能标记真实 succeeded。
- 独立 public-site SSR，仅渲染当前 release；预览和正式页共享组件。SEO 从 release 快照读取；无伪造评价，提供实际页面结构化数据、robots/sitemap；模拟页面 noindex。
- 匿名表单接入 T6 统一隐私批准门槛，默认关闭真实 PII 接收；Origin 校验、16KB 流式大小上限、严格请求字段、独立营销同意、最小联系方式、持久幂等和频率控制。非法字段只返回通用错误，不回显联系人数据。
- 草稿预览仅通过受组织身份保护的管理 API；public-site 的匿名 preview 路径返回 404。服务重验当前数据库成员权限；公网站点缓存数据库连接池，GET 不执行 seed。
- 管理 API 提供内容/页面/档案/变体/发布任务读写；平台发布仅持久化授权动作和 job，不把提交或排期当实际发布成功。
