## 最终联调

AC35 主线：四源变化 → 洞察选题 → 实际素材 → 官网与所选平台发布 → 百度执行 → 接待/表单咨询 → 共享线索及销售反馈 → 日报通知 → Drive 回读 → 下一轮计划。

跨模块故障验收同时覆盖：

- 规则撤销、预算/频次到限后阻止后续写入。
- 提交超时、回执丢失、worker 或浏览器重启后先对账，保持同一动作/命令身份，避免重复写入。
- 隐私未启用时阻断真实个人信息采集，撤回后取消后续营销任务。
- 16 渠道按 AC47 汇总实际能力与证据；缺少必需真实证据继续显示待验收。

最终完成标准继续遵循原 PRD AC01–AC47；界面确认只授权进入实施，不能代替功能或生产集成验收。
